These documents are historical design and implementation records kept for
provenance. They are **not** part of the public documentation:

- they may reference an internal specification's section numbers,
- they describe decisions and status as of the date they were written, and
- they can be stale.

The authoritative user documentation is [docs/README.md](../README.md).
